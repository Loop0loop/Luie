# 문맥 선택

먼저 요청과 현재 코드에서 필요한 영역을 판단한다. 저장소·하위 AGENTS를 적용하고, 스킬을 사용할 때 그 SKILL.md를 읽는다. 보조 문서는 현재 변경·오류와 관련된 것만 선택한다.

정확한 파일이 알려져 있으면 해당 파일·호출자·테스트로 좁힌다. 그래프는 관계 탐색에 활용하고, 누락·오래된 결과는 현재 소스로 보완한다. 존재하지 않는 examples·memory·difficulty 문서를 찾는 것을 선행 조건으로 만들지 않는다.

큰 자료는 관련 절부터 찾는다. 읽지 않은 부분까지 검토했다고 주장하지 않는다. 작업·코드가 바뀌지 않았다면 같은 지침을 반복해서 읽지 않는다.
