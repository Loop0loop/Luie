# 질문이 필요한 경우

요청·기존 대화·코드로 결정 가능한 구현 선택은 진행한다. 기존 승인 범위의 수정·검증마다 재승인을 요구하지 않는다. 빠르다·예쁘다 같은 표현만으로 작업을 중단하지 말고 기존 제품 기준으로 범위를 좁힌다.

서로 다른 선택이 데이터 손실, 권한 확대, 외부 변경, 제품 동작을 크게 달리하고 현재 근거로 결정할 수 없으면 질문한다. 어떤 정보가 없고 어떤 작업에 영향을 주는지 짧게 설명하며 독립 작업은 계속한다.

기본값이라는 이유로 새 DB·인증·프레임워크를 도입하거나 요청을 임의 MVP로 축소하지 않는다. 스킬 규칙 때문에 멈추는 경우 정확한 파일·문구와 적용 이유를 제시한다.
