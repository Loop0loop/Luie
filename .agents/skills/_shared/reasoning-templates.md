# 근거 기록

복잡한 조사·인수인계에서 필요하면 다음 정보를 짧게 기록한다. 고정 표나 단계별 사고 기록은 요구하지 않는다.

- 오류 조사: 관찰된 증상, 원인 가설, 확인 방법·결과, 남은 불확실성.
- 구조 결정: 관련 코드·제약, 선택한 변경과 실제 tradeoff.
- 성능: 입력 크기·환경·명령, 전후 측정값, 측정하지 못한 범위.
- 인수인계: 완료 작업·파일, 관련 검증, 남은 작업·막힌 이유.

시도 횟수만으로 중단하지 않는다. 새로운 근거가 없는 동일 검증 반복은 피하고, 사용자 결정이나 환경 변화가 필요한 지점을 설명한다.
