# 도구 설정

목록·상태 요청은 읽기 전용으로 처리한다. 변경 요청은 대상 도구와 현재 환경의 실제 설정 스키마를 확인한 뒤 지정한 범위만 수정한다.

프로젝트 설정과 사용자 전역 설정을 구분한다. 문서·메모리에 도구 제한을 적는 것을 실제 권한 차단으로 설명하지 않는다. 세션 한정 요청을 영구 설정으로 바꾸지 않는다.

민감정보는 출력하지 않는다. 설치·계정 연결·허용 권한 확대가 필요하면 기존 요청에 권한이 있는지 확인한다. 수정 후 설정 구문과 가능한 연결 검증을 수행하고, 재시작이 필요하면 알린다.
