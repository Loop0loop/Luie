# 다중 에이전트 실행

[coordinate](coordinate.md)의 파일 소유권·계약·검증 기준을 따른다.

기존 요청과 계획을 활용하고, 누락된 형식 파일이나 Gemini/Serena CLI 때문에 실행을 중단하지 않는다. 도구·모델 선택은 현재 환경과 사용자의 명시적 선택을 따른다. 실패가 나면 원인을 확인해 해당 작업을 수정·검증하며 동일 호출을 무한 반복하지 않는다.

모든 결과를 통합하고 관련 검증과 남은 실패를 보고한다. 별도 task board·progress 파일은 실제 인수인계가 필요한 경우에만 만든다.
