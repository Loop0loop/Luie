# 병렬 작업 조율

사용자가 병렬 에이전트 작업을 요청한 경우 사용한다. [공통 지침](../../AGENTS.md) 안에서 현재 제공된 위임 기능으로 실행한다. 별도 CLI·MCP·PM agent 설치는 선행 조건이 아니다.

서로 독립적인 작업에 범위·소유 파일·입출력 계약·검증 조건을 전달한다. 같은 파일의 동시 수정을 피하고 계약이 미정인 의존 작업은 순서대로 처리한다. 주 작업자는 독립 작업을 계속하며 결과를 합칠 때 diff와 경계 테스트를 확인한다.

원래 요청에 구현 권한이 있으면 계획 제시 후 재승인 없이 이어간다. 위임이 불가능하면 직접 진행하고 제약을 보고한다. agent를 만들었다는 사실 자체를 완료로 취급하지 않는다.
