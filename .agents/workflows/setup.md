# 설정

대상이 앱 개발 환경인지 특정 에이전트/연결인지 요청에서 판단한다. 앱 도구·버전은 `package.json`, 에이전트 설정은 해당 도구가 실제로 읽는 프로젝트 파일과 공식 문서를 확인한다.

필요한 CLI·연결만 확인하고, 출력에 비밀·토큰을 노출하지 않는다. 언어 기본값은 한국어다. 이미 알려진 언어·프레임워크·CLI 선택을 다시 묻지 않는다.

요청된 설정 수정과 검증을 수행한다. 모든 Gemini/Claude/Codex CLI의 설치, 사용자 전역 설정 변경, 새 서비스 연결을 기본 작업으로 삼지 않는다. 연결 정보를 파일에 적은 것과 실제 연결 성공을 구분해 보고한다.
