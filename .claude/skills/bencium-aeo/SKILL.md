# 근거 있는 공개 콘텐츠

대상 페이지·독자·질문·검증 가능한 자료를 확인한다. AI 기능 코드나 Luie 내부 원고/RAG 작업이라는 이유만으로 이 스킬을 적용하지 않는다.

요청한 콘텐츠를 명확한 답변, 출처·방법·날짜·한계로 구성한다. FAQ·evidence panel·JSON-LD는 페이지 내용과 목적에 맞을 때 작성한다. 개수·단어 수를 고정하거나 검색 노출 향상을 보장하지 않는다.

`prd.md`는 HTML/FAQ 양식이 필요할 때, `story-structured.md`는 연구 배경을 검토할 때 참고한다. 기존 자료의 18-token 법칙·특정 향상률·최신성 수치는 검증된 일반 법칙으로 취급하지 않는다. 적용하려면 원 연구와 조건을 확인한다.

구조화 데이터는 실제 페이지 내용과 일치시킨다. 실제 변경 없이 최신 날짜를 갱신하거나 증거·성과를 만들지 않는다. 공개·외부 계정 게시·장기 모니터링은 해당 요청 범위를 확인한다.
